# Журнал изменений

Все значимые изменения проекта фиксируются в этом файле.

## [1.2.0] — 2026-11-06

### Добавлено
- Комплект технической документации проекта.
- Диаграммы архитектуры и структуры базы данных.
- Инструкции локального запуска и облачного развёртывания.
- Описание REST API и типичных ошибок.
- Автоматическая генерация OpenAPI-схемы и интерфейс Swagger.

### Улучшено
- Настройка приложения через переменные окружения.
- Подготовка статических файлов для развёртывания.
- Воспроизводимость установки приложения.

## [1.1.0] — 2026-11-05

### Добавлено
- Бизнес-логика бронирования оборудования.
- Управление статусами бронирований.
- История событий.
- REST API для операций с бронированиями.
- Автоматические тесты.

## [1.0.0] — первоначальная версия

### Добавлено
- Авторизация пользователей.
- Управление факультетами, группами, курсами и студентами.
- Пользовательский интерфейс Django.
