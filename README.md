# Система бронирования оборудования

## 1. Описание проекта

Веб-приложение для бронирования оборудования,
разработанное на Django и Django REST Framework.
Система позволяет пользователям просматривать
оборудование, создавать и управлять бронированиями,
отслеживать их состояние и историю действий.

## 2. Основные возможности

- Авторизация пользователей.
- Просмотр доступного оборудования.
- Поиск и фильтрация оборудования.
- Создание и редактирование бронирований.
- Подтверждение и завершение бронирований.
- Автоматический учёт доступного оборудования.
- Просмотр истории действий.
- Получение статистики через REST API.

## 3. Технологии

- Python 3.13.7
- Django 6.1.3
- Django REST Framework 3.18.3
- SQLite для локального запуска
- HTML, CSS, JavaScript
- python-dotenv 1.2.4

## 4. Структура проекта

- accounts/ — авторизация и пользовательские функции.
- config/ — настройки Django.
- reservations/ — бронирования и REST API.
- templates/ — HTML-шаблоны.
- static/ — статические файлы.
- docs/ — техническая документация.
- manage.py — управление проектом.
- requirements.txt — зависимости.
- .env.example — образец конфигурации.

## 5. Локальный запуск

Для запуска необходим Python 3.13.

### Создание окружения

Для Windows PowerShell:

    py -3.13 -m venv .venv

    .\.venv\Scripts\Activate.ps1

### Установка зависимостей

    python -m pip install -r requirements.txt

### Настройка окружения

Скопировать .env.example в .env:

    Copy-Item .env.example .env

Сгенерировать секретный ключ:

    python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"

Заменить DJANGO_SECRET_KEY в файле .env
на полученный ключ.

Настройки локального запуска:
- DJANGO_DEBUG=True
- DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost

Файл .env нельзя публиковать в репозитории.

### Создание базы данных

    python manage.py migrate

### Создание администратора

    python manage.py createsuperuser

### Запуск сервера

    python manage.py runserver

Адрес приложения:

http://127.0.0.1:8000/

## 6. Проверка работы

Проверка конфигурации:

    python manage.py check

Автоматические тесты:

    python manage.py test

Проверка зависимостей:

    python -m pip check

Административная панель:
http://127.0.0.1:8000/admin/

Страница бронирований:
http://127.0.0.1:8000/reservations/

API оборудования:
http://127.0.0.1:8000/api/equipment/

API бронирований:
http://127.0.0.1:8000/api/reservations/

Для работы с API требуется авторизация.
После создания новой базы оборудование необходимо
добавить через административную панель.

## 9. Безопасность

Настройки окружения хранятся в .env.
Настоящие секретные ключи и пароли не должны
попадать в GitHub.
Для изменения бронирований необходима авторизация.
Подтверждение и завершение бронирований
выполняются с использованием транзакций.

## 10. Заключение

Документация позволяет подготовить локальное
окружение, создать базу данных и запустить
веб-приложение без использования готовой
локальной базы.
Работоспособность подтверждена автоматическими
тестами и проверкой пользовательских сценариев.
